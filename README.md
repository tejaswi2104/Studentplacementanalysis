
# PlacementIQ – Student Placement Data Analysis System

## Project Overview
PlacementIQ is a web-based student placement data analysis system developed using Python and Streamlit.

It helps analyze student placement outcomes, department-wise placement statistics, salary packages, and student skills through interactive dashboards and visualizations.

## Objectives
- Analyze student placement outcomes.
- Calculate placement percentage using eligible students.
- Compare placement statistics across departments.
- Analyze salary package distributions.
- Understand skills available across student profiles.
- Generate downloadable placement reports.

## Technologies Used
- Python
- Streamlit
- Pandas
- NumPy
- Plotly

## Features
1. Placement Overview Dashboard
2. Student Management
3. Placement Management
4. Department Analysis
5. Package Analytics
6. Skill Analysis
7. CSV Data Import Preview
8. Report Generation

## Placement Rate Formula

Placement Rate = (Number of Eligible Students Placed / Total Eligible Students) × 100

## Sample Dataset
The application uses 100 fictional student records for academic demonstration purposes. These records do not represent actual university placement data.
